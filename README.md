# 💳 Bank Fraud Detection

A Data Analytics and Machine Learning project that analyzes credit card transactions and identifies potentially fraudulent activities using **Logistic Regression** and **Random Forest** classification models.

## 📊 Project Overview

Credit card fraud is a major challenge in the financial industry. This project uses an anonymized transaction dataset to explore transaction patterns, analyze fraudulent activities, and build machine learning models to classify transactions as fraudulent or legitimate.

The project follows a complete machine learning workflow, from Exploratory Data Analysis (EDA) and data preprocessing to model evaluation and dashboard deployment.

**Dataset highlights:**
- Total transactions: 284,807
- Fraudulent transactions: 0.17% of the dataset
- Problem type: Binary classification
- Target classes: Fraudulent and legitimate transactions

## 📂 Dataset

The project uses the **Credit Card Fraud Detection** dataset from Kaggle.

**Dataset link:** [Credit Card Fraud Detection – Kaggle](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud)

The dataset contains anonymized credit card transactions, including numerical features generated using Principal Component Analysis (PCA), along with transaction amount, time, and a fraud indicator.

Due to GitHub's file size limitations, the dataset is not included in this repository.

**Setup:**
1. Download the dataset from Kaggle.
2. Extract the CSV file.
3. Place it inside the `data/raw/` directory.

## 🤖 Machine Learning Models

### 1. Logistic Regression
Used as a baseline classification model to establish an initial performance benchmark.

### 2. Random Forest Classifier
Used as the final classification model to capture more complex relationships in transaction data and identify potentially fraudulent transactions.

Model performance is evaluated using precision, recall, and F1-score, which are particularly relevant for imbalanced classification problems.

## 📈 Model Performance

The following are the reported evaluation results:

| Model | Precision | Recall | F1-Score |
|---|---:|---:|---:|
| Logistic Regression | 0.06 | 0.91 | 0.11 |
| Random Forest | 0.92 | 0.81 | 0.86 |

**Interpretation:**
- **Precision:** Measures how many transactions predicted as fraudulent were actually fraudulent.
- **Recall:** Measures how many actual fraudulent transactions were correctly identified.
- **F1-score:** Combines precision and recall into a single metric.

Based on these reported results, Random Forest provides a stronger balance between precision and recall than the Logistic Regression baseline.

*Note: These results should be verified against the final test-set evaluation from the project notebook.*

## 🔍 Key Insights

The analysis explores the following patterns:

- **Fraud frequency:** Examines how fraud rates vary across transaction times.
- **Transaction behavior:** Investigates whether transaction amounts and patterns differ between fraudulent and legitimate transactions.
- **Important features:** Analyzes the contribution of anonymized PCA features, including V14, V10, and V4, to fraud classification.
- **Class imbalance:** Highlights the challenge of detecting fraudulent transactions when legitimate transactions make up the overwhelming majority of the dataset.

## 🚀 Getting Started

### Prerequisites

Install Python and download the dataset before running the project.

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/Bank_Fraud_Detection.git
cd Bank_Fraud_Detection
```

Replace `YOUR_USERNAME` with your GitHub username.

### 2. Install Dependencies

```bash
pip install -r requirements.txt
```

### 3. Download the Dataset

Download the CSV file from Kaggle and place it in `data/raw/`.

### 4. Run the Analysis

Open the Jupyter Notebook:

```bash
jupyter notebook
```

Navigate to the `notebooks/` directory and run the analysis notebook.

### 5. Launch the Streamlit Dashboard

```bash
streamlit run app/dashboard.py
```

The dashboard will open in your browser if the application is configured correctly.

## 💡 Business Applications

This project demonstrates how machine learning can support financial fraud detection by:

- Flagging suspicious transactions for further investigation.
- Helping analysts understand transaction patterns.
- Supporting data-driven fraud monitoring.
- Demonstrating the importance of precision and recall in imbalanced classification problems.

The model is a learning and demonstration project, not a production-ready financial fraud detection system.
